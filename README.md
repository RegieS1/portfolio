# Portfolio

A single-page developer portfolio built with Astro, Tailwind CSS, and TypeScript.

## Quick start

```bash
npm install
npm run dev
```

## Edit content

All text, stats, and projects live in `src/data/site.ts`. Change that file and the page updates automatically.

## Deploy to Netlify

| Setting           | Value       |
| ----------------- | ----------- |
| Build command      | `npm run build` |
| Publish directory  | `dist`      |

Connect the repo to Netlify, set the two values above, and deploy.
